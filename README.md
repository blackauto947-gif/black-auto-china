# Black Auto China — clean build

## Что внутри
- Главная страница
- Каталог автомобилей
- Детальная страница автомобиля
- Страница заявки
- Телефон: 89084590218
- Кнопка «Кабинет»
- Раздел Stock 3
- Множественная загрузка файлов с сохранением списка в браузере

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```

Важно: этот проект не использует алиасы путей и не импортирует отсутствующие файлы, поэтому ошибка `Module not found` из предыдущей сборки устранена.
