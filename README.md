# Black Auto China

Готовый проект Next.js.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Что есть

- Главная страница и каталог.
- Карточки автомобилей.
- Детальная страница автомобиля.
- Первая фотография в карточке/галерее предназначена для фото двигателя и кузова.
- Страница заявки.
- Телефон: `8 908 459-02-18`.
- Кнопка **Кабинет**.
- Кабинет `/admin` с папкой **STOCK 3** и загрузкой файлов.
- Список заявок и список файлов сохраняются в браузере через localStorage.

## Важно про постоянную загрузку

Этот архив специально не требует ключей Supabase и поэтому не падает на сборке из-за отсутствующих переменных окружения. Для настоящего серверного хранения файлов потребуется подключить Storage (например Supabase).
