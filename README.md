# BLACK AUTO CHINA

## Запуск
1. Установите Node.js 20+
2. Скопируйте `.env.example` в `.env.local`
3. Вставьте URL и Publishable Key Supabase
4. `npm install`
5. `npm run dev`

## Публикация
Загрузите проект в GitHub, импортируйте репозиторий в Vercel и добавьте те же две переменные окружения.

Функции:
- каталог автомобилей
- Supabase Auth
- админ-панель
- добавление, редактирование, удаление
- загрузка фотографий в `car-images`
- расчёт: (цена авто + доставка CNY) × курс CNY/RUB
- управление курсом и транспортными расходами
